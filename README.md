# ☕ Chai Culture — Coming Soon Page

A premium animated **Coming Soon landing page** for **Chai Culture**, a luxury instant chai premix brand inspired by royal Indian traditions.

🌿 Designed with elegance  
✨ Smooth animations  
📱 Fully responsive  
🚀 Deployed online

---

## 🌟 Features

- 🎨 Luxury UI with gold & royal tones  
- ✨ Animated shimmer “Coming Soon” text  
- 🖼 Floating image gallery (desktop)  
- 📱 Clean responsive layout for mobile  
- 📩 Signup form with success message  
- 🧈 Smooth scrolling navigation  
- ⚡ Fast static website (no frameworks)
